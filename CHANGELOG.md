# Changelog

All notable changes to this project are documented in this file.

## 0.1.0-beta.3 - 2026-10-08

- Publish the Talred-prefixed API client contract under `@talred/api-client`.
- Point package metadata at the canonical `talredservices/talred-api-client`
  repository.

## 0.1.0-beta.2 - 2026-10-08

- Publish the Service Talred package under the `@talred/api-client` scope with
  Talred-prefixed public exports and examples.

## 0.1.0-beta.1 - 2026-08-15

- Add the framework-neutral Zolta HTTP client.
- Add typed response envelopes and normalized API errors.
- Add bearer, internal-service-token, and unauthorized lifecycle hooks.
